# Part·차시 · 강의 제목

CoopRPG · 작성일 YYYY-MM-DD · 상태: 초안/검토 중/근거 확인

강의: 제목·URL을 확인해 연결 · 예제: 확인한 브랜치·파일을 연결 · 강의 엔진 버전: 확인값 또는 미확인

근거 범위: 예) 강의 스크립트 전체 확인 / 예제 소스 확인 / 직접 실행 미실시

## 이 강의가 답하는 질문

질문과 핵심 답을 짧게 쓴다. 앞선 강의와의 연결이 필요하면 한두 문장으로 덧붙인다.

## 핵심 원리와 적용 조건

개념의 역할, 필요한 이유, 서버·클라이언트 중 실행 위치, 적용 조건을 설명한다. 헷갈리기 쉬운 용어가 있으면 경계를 적는다.

## 예제 코드와 실행 흐름

실제 소스와 대조했을 때만 파일 경로를 단정한다. 강의 자막에서만 확인한 함수는 '강의 설명'으로 표시한다.

| 출처·확인 상태 | 파일·함수 | 역할·호출 시점 |
|---|---|---|
| 강의 설명 / 소스 확인 / 직접 실행 중 해당 상태 | 경로 또는 미확인 | 내용 |

흐름의 위치와 순서가 중요하면 짧은 단계나 Mermaid 다이어그램을 추가한다. 긴 코드는 원본 링크로 대신한다.

## 관찰과 해석

강의 시연에서 확인한 결과와 직접 실행한 결과를 분리한다. 관찰이 입증하는 범위와 아직 확인하지 못한 조건을 적는다. 직접 시험 결과의 원본은 Validation에 연결한다.

## CoopRPG에 연결할 점

현재 리슨 서버 구현에 필요한 판단과 관련 코드·작업을 적는다. 적용 전의 아이디어는 제안으로 표시한다. GAS 또는 전용 서버에서 다시 확인할 항목은 실제 연관성이 있을 때만 덧붙인다.

## 다시 확인할 질문·출처

복습할 질문, 강의 시간대, 예제·공식 문서·프로젝트 기록 링크를 필요한 만큼 적는다. 완료·미확인 상태가 섞이면 구분한다.

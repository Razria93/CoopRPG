## 2. 최종 제작 목표: 2인 협동 보급 회수·탈출

추천 목표는 Windows 데디케이트 서버 1개와 별도 클라이언트 2개로 실행하는 작은 협동 게임이다. 낙원에서 참고할 부분은 위협 속에서 보급품을 회수하고 탈출을 결정하는 흐름이다. 고유 제목과 사용 가능한 기본 자산으로 구성하고, 도시 전체나 PvPvE 규모를 재현하려 하지 않는다.

| 항목 | 이번 제출용 제안 |
|---|---|
| 한 판 | 2명 접속 → 출발 → 적을 피해 이동하거나 전투 → 공동 보급량 확보 → 두 명 함께 탈출 → 결과 → 재시작. |
| 공간과 콘텐츠 | 작은 고정 맵 1개, 플레이어 형태 1개, 근접 공격 1개, 적 유형 1개. 그레이박스와 기존 사용 가능 자산 중심. |
| 구체 규칙 | 상자 3개에 보급 1개씩, 공동 목표 2개, 제한 시간 5분, 생존한 두 플레이어가 탈출 구역에 연속 3초 머무르면 성공. 목표 달성 후 추가 상자는 선택 점수. 수치는 새로 제안한 값이다. |
| 실패와 취소 | 한 명 사망 또는 시간초과면 실패. 탈출 도중 한 명이 구역을 나가면 진행 시간이 초기화된다. 접속 종료는 중단 결과로 처리하고, 중도 참가·자동 재접속은 지원하지 않는다. |
| 상태 관리 | 서버가 Waiting → Playing → Result를 전환하고 결과는 한 번만 확정한다. Playing의 참가자 수는 2명으로 고정. 결과 화면에서 각자 준비 후 다음 라운드를 시작하며 모든 속성·상자·적·시간을 초기화한다. |
| GAS 범위 | 공격 Ability, HP·스태미나 Attribute, 피해·비용·쿨다운 Effect, 필요한 상태 Tag. 적의 피해 처리와 플레이어 상태를 일관된 경로로 연결한다. |
| 네트워크 범위 | 서버가 피해·수집·탈출·라운드 결과를 확정. CharacterMovement 기반 이동과 제한된 공격 예측 반응을 사용. 클라이언트가 보낸 대상·거리·중복 요청을 그대로 신뢰하지 않는다. |
| UI | HP·스태미나, 공동 수집량, 남은 시간, 탈출 진행, 결과와 재시작 안내만 표시. |
| 실행 환경 | 우선 동일 PC의 별도 프로세스로 검증. 가능하면 다른 PC/LAN에서 추가 확인. 인터넷 서비스 운영, 클라우드, 공개 매칭은 이번 목표에서 제외. |

이번 범위에서는 다운·부활, 대시, 여러 무기, 연속 콤보, 장비 슬롯, 제작, 영구 저장/DB, PvP, 절차적 맵, 매칭과 외부 서비스 연동을 제외한다. 단순 공동 수집과 함께 탈출하는 조건으로 협동 목적을 유지한다. 시간이 남더라도 제출 전에는 검증·가독성·플레이 명료성을 개선한다.

서버의 타격 처리는 렌더링 유무에 영향을 받지 않게 설계한다. 예를 들어 서버가 정한 공격 시간과 공간 검사로 타격을 확정하고 애니메이션은 이를 표현한다. 클라이언트의 빠른 반응과 서버 피해 확정은 구분하며, 이번 범위에서 지연 보상이나 모든 상황의 예측 복구를 완성했다고 주장하지 않는다.

## 3. 수강과 이해 확인 방법

표의 P1~P4는 이득우의 Part1~4이며 번호는 제목에 적힌 ‘n강’ 기준이다. Part1·2의 소개 영상 때문에 사이트의 목록 순번과 하나씩 다를 수 있다. 각 날짜의 학습 시간은 영상 재생뿐 아니라 작은 실습·설명·재확인을 포함한 예산이다.

| 강의 | 마감 전 핵심 배치 | 마감 이후 보완 |
|---|---|---|
| Part1 | 3~9강, 12강, 15강. 1~2강은 첫날 진단에서 막힐 때 복습. | 10~11강 자료구조, 13~14강 직렬화·패키지. 필요한 개념이 작업 중 드러나면 해당 부분을 먼저 보충. |
| Part2 | 1~4강, 6강, 8강, 11~12강, 14~15강. | 5강 콤보, 7강 위젯 기초, 9강 맵, 10강 데이터, 13강 HUD. UI를 이해하기 어렵다면 7·13강을 우선 보충하고 장식 작업을 줄임. |
| Part3 | 1~6강, 8~11강. | 7강 하위 복제 흐름, 12~13강 물리·이동 확장, 14~15강 아이템·PvP. 당장은 기본 이동·단순 카운터로 범위를 제한. |
| Part4 | 1~8강. 4강의 콤보 구조는 Ability 수명 이해에 활용하되 제출 게임에는 단일 공격만 사용. | 9~10강 응용. 핵심 검증을 끝낸 다음 확장. |

공개 목차의 개별 영상 시간으로 계산한 핵심 37강은 약 25시간 47분이다. 4개 과정 전체 표기 시간의 합은 약 40시간 36분이다. 실습·재시청·버전 차이 대응은 이 시간에 포함되지 않는다. 이 선별 일정은 기초 학습의 완료 선언이 아니다.

- 매 강의 후 ① 화면을 보지 않고 원리 설명 ② 작은 요구 변경을 직접 수행 ③ 실행 결과로 확인한다. 셋 중 하나가 막히면 해당 개념을 ‘이해 완료’로 표시하지 않는다.
- 강의 실습은 작은 학습 프로젝트에서 수행하고, 이해한 최소 기능을 본 프로젝트에 적용한다. 강의 예제 전체와 신규 게임을 동시에 확장하지 않는다.
- AI에게 맡기기 전에 목표·변경 범위·성공 조건을 사람이 적는다. AI의 코드·대안·테스트 제안을 검토한 뒤 채택/수정/거절 이유를 남긴다.
- 자신이 직접 읽어야 할 경로는 입력 → Ability 실행/종료, 서버 요청 → 검사 → 상태 변경 → 복제, 결과 → 초기화의 세 경로다.
- 강의 예제 버전과 현재 프로젝트 엔진의 API 차이는 생길 수 있다. 기존 엔진 버전을 고정하고 필요한 차이만 확인한다. 마감 전 무계획한 엔진 업그레이드를 일정에 넣지 않는다.
- 매일 종료 때 통과한 것, 실패한 것, 다음 날 가장 먼저 할 일 하나를 기록한다. 지연된 작업을 다음 날 목표 위에 계속 더하지 않는다.

# AI 협업 역할·행동 근거 색인

CoopRPG · 2026-11-16 · 포트폴리오 편집용 내부 색인

사용자가 작업 환경·계획·설계·검증에서 실제로 맡은 책임과 AI의 수행 범위를 원본 근거에 연결한다. 이 색인은 사례를 계속 수집하는 작업 기록이며, 최종 포트폴리오에 실을 사례의 확정 목록은 아니다.

## 수집·갱신 기준

- **수집 대상:** 사용자가 문제·목표·정보 요구를 정의하거나, 작업 계획과 구조·규칙을 선택·수정하거나, 직접 조작·대조·검증한 사건. 코드 컨벤션, 에이전트 규칙, 검증 하네스, 문서 양식·스킬의 구성·갱신도 실제 행동과 적용 결과가 확인될 때 포함한다.
- **한 사례 한 행:** 같은 목적에서 이어진 사용자 판단, AI 구현·자동 시험, 사용자 재확인은 기존 행을 갱신한다. 별도 책임·결정·검증 경계가 생길 때만 행을 추가한다. 관련 역량은 한 행에 함께 적을 수 있다.
- **출처와 상태:** 사용자 제안·채택·직접 검증을 각각 구분한다. AI 제안·구현·자동 시험은 사용자 행동이나 사람 확인으로 바꾸지 않는다. 계획/채택, 문서·도구 적용, 자동 확인, 사용자 직접 확인, 게임 기능 검증을 별도 상태로 적고, 근거가 없는 효과는 미확인으로 남긴다.
- **갱신 시점:** 의미 있는 결정·적용·검증이 생긴 작업 마무리에 원본 기록을 먼저 갱신하고 이 표의 같은 행과 링크를 대조한다. 새 사용자 확인이 들어오면 기존 행의 상태와 근거를 갱신한다. 포트폴리오 수록 여부는 [사례 후보](../Development.md#portfolio-case-candidates)에서 최종 편집 때 판단한다.

## 편집 시 확인

현재 표는 확인된 행동과 상태를 찾기 위한 색인이다. 최종 문구에는 적용 날짜·실행 조건·기능 완료 범위를 원본과 다시 대조한다. AI 자동 시험만 있는 사례는 적용·검증 상태에 `사용자 확인 대기` 또는 `사용자 확인 미실시`를 상황에 맞춰 적는다. 새 사용자 확인이 생기면 해당 행의 상태와 원본 링크를 갱신한다.
